# v3.42 发布核验

日期：2026-10-19。范围是独立发布副本，未改变正在使用的主海港网页。

## 可运行性

- 用 `scripts/serve.py --port 8767` 在独立端口启动发布目录；根入口跳转后实际渲染完成。
- 在 Edge 无界面浏览器中切换白天／夜晚，核对控制状态与画面。
- 四段环境录音从发布目录成功读取并解码：海浪约 57.68 秒、海风 9.53 秒、海鸥 17.14 秒、小店 137.44 秒。
- 390 × 844 窄屏无横向页面溢出。窄屏仍采用当前网页的裁切构图，不等同于手机硬件测试。
- 本轮加载中未发现浏览器运行异常或 HTTP 资源错误。
- README 图片来自这次 1500 × 1000 实际网页捕获；桌面与窄屏截图均做了人工目视核对。

## 资产与来源

- 五份 Blender 工程以独立副本打开；补齐仍引用原目录的图像，统一打包并改为相对路径，再复开检查。
- GLB 的几何、骨骼和贴图文件保留当前工作区版本，外部图像地址均能在仓库内解析。
- 人物 manifest 的几何浮点记录缩短为八位有效数字，足够保留脚底采样精度；原工程 SHA-256 保留，同时记录发布副本 SHA-256。
- 18 张 WebP 经缩略图逐张核对，为场景／人物材质贴图。README 图片只含项目画面；四段 MP3 与已核验的 Freesound 来源哈希一致。
- 保留 Three.js、Draco 的许可原文以及 Quaternius、Poly Haven、Freesound 的出处。没有上传其他作者的参考截图和视频。

## 隐私扫描

对候选文件和最终 Git 暂存区分别运行发布技能的审计脚本。自动扫描将守塔人原工程 SHA-256 中的一段数字识别成手机号；逐字段核对后确认为校验哈希误报。脚底坐标的高精度小数也曾触发号码规则，已规范为八位有效数字。没有因此删除或伪造哈希。

音频、贴图和 README 图片的二进制审查警告经过单独来源／内容核对。扫描属于启发式检查，不声称能够证明所有内容绝对没有风险。

## 验证边界

此轮没有重新验收所有互动动作、全岛每个角度的几何接触，也没有测公共网络加载速度或真实手机帧率。选定模型的导出脚本已检查引用与路径，未在发布过程中完整重跑耗时的全部模型导出链。
